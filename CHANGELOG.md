# Changelog

## 1.0.0

First release as its own GitHub repo.
- Install by pasting the repo link into Claude Code and saying "set this up".
- The kit lives in `solnest/meetings-and-notes-kit` in your home folder. Setup puts it there.
- Updates install themselves once a day, in the background, from published releases only. If a new release does not load, the old one is put back by itself.
- An update never touches your connections in Claude Code, any `.env` file, or any file you added. Changes you ask for are kept in `~/.solnest/meetings-and-notes-kit/my-instructions.md`.
